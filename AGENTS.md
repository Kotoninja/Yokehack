# AGENTS.md

Инструкции для агентов, работающих с репозиторием. Суть задачи и архитектура описаны в `README.md`.

## Окружение

- Python 3.12 через `uv`. Команды запускать как `uv run python -m forecast.<module>`, а не голым `python`.
- LightGBM на macOS требует `libomp` (`brew install libomp`).
- Данные: `Data/train_solo_track.parquet` (4.63 млн строк), `Data/test_solo_track.parquet` (8000 строк). В git их нет.

## Инварианты, которые нельзя ломать

- **Нет утечки.** Признаки для якоря `a` используют только индексы времени `≤ a`. Таргет — `y[:, a+k]`, `k = 1..8`. Любой новый признак проверять на это.
- **Сетка.** `load_panel` требует полную сетку маршрут × время, начинающуюся в 00:00. От этого зависят `slot = j % 48` и `dow = (j // 48) % 7` (данные начинаются в понедельник).
- **Тестовый якорь** — последняя точка train (индекс `T-1`, слот 21 = 10:30).
- **Валидация** — последние 14 якорей в слоте 21. Обучающие якоря должны удовлетворять `a + 8 ≤ первый валидационный якорь`.
- **Посылка:** ровно 8000 строк, `id` уникальны и совпадают с тестом, без NaN, `y_pred ≥ 0`. Проверки — в `pipeline.py` и `train_predict.py`, не удалять их.

## Как сравнивать модели

- Основная метрика сравнения — `sum_matched` (`experiment.py`): скор после приведения суммы прогноза за каждый день к факту. `raw` смотреть вторым.
- Посылку строит `forecast.pipeline`: веса, итерации и уровень (общая сумма) берутся только из валидации. Параметры с лидерборда в пайплайн не добавлять.
- `--target-sum` в `train_predict.py` — ручной режим для экспериментов; посылки с ним откалиброваны по лидерборду (~2.23e9) и лежат в `runs/lb_probes/`.
- Результаты экспериментов дописываются в `runs/results.jsonl`, прогнозы — в `runs/val_<name>.parquet`.

## Время выполнения

- Сборка признаков: ~15 с на 600 якорей. Кэш лежит в `runs/feat_r{radius}_{tr,va}.parquet`. При изменении `features.py` кэш нужно удалить.
- Обучение: от минут (lr 0.1, `max_bin` 63, radius 2) до ~50 мин (lr 0.05, radius 4). Долгие прогоны запускать в фоне с логом в `runs/`.
- Не запускать два обучения параллельно: оба используют все ядра.

## Подводные камни

- Шелл — zsh: переменная со строкой команды (`$E args`) не разбивается на слова. Для серий запусков писать bash-скрипт с массивом `"${E[@]}"`.

## Стиль

- Комментарии и сообщения — на русском, идентификаторы — на английском.
- Новые варианты моделей добавлять в `VARIANTS` в `experiment.py`, а не отдельными скриптами.
- Файлы посылок (`*.csv` в корне) и `runs/` не коммитить.
